## What it does

  <div class="ruled__row">

    <span class="ruled__detail">

  <div class="ruled__row">
    <span class="ruled__index">03</span>
    <span class="ruled__name">Autoplay</span>
    <span class="ruled__detail">
      The related tracks of the source keep the queue going, without any extra work.
    </span>
  </div>
  <div class="ruled__row">
    <span class="ruled__index">04</span>
    <span class="ruled__name">A real plugin system</span>
    <span class="ruled__detail">
      Write your own source in a few lines. It can search, it can play, and it can hand the audio of
      a track that it cannot play itself to another plugin.
    </span>
  </div>
  <div class="ruled__row">
    <span class="ruled__index">05</span>
    <span class="ruled__name">Typed from the ground up</span>
    <span class="ruled__detail">
      Every option, event and error is typed. The editor tells you what is possible, and the
      reference tells you what it does.
    </span>
  </div>

## A whole bot in twenty lines

```js
import { DisTube, Events } from "distube";
import { Client, GatewayIntentBits } from "discord.js";

const client = new Client({
  intents: [
    GatewayIntentBits.Guilds,
    GatewayIntentBits.GuildVoiceStates,
    GatewayIntentBits.GuildMessages,
    GatewayIntentBits.MessageContent,
  ],
});

const distube = new DisTube(client);

distube.on(Events.PLAY_SONG, (queue, song) => {
  queue.textChannel.send(`Playing **${song.name}** — ${song.formattedDuration}`);
});

client.on("messageCreate", async (message) => {
  if (!message.content.startsWith("!play")) return;
  const query = message.content.slice(6).trim();
  if (!query) return;

  await distube.play(message.member.voice.channel, query, {
    message,
    member: message.member,
    textChannel: message.channel,
  });
});

client.login(process.env.DISCORD_TOKEN);
```
